# Unlock Music Tool Pro (UMT Pro)

Unlock Music Tool Pro 是一款为音乐爱好者打造的批量音频处理工具。它集成了**批量解密**、**标签自动修正**、**高清封面抓取**等功能，旨在解决解密后音乐文件元数据（Metadata）缺失、混乱或乱码的问题。

## 🌟 核心特性

- **智能标签修复**：基于文件名的“强制对齐”逻辑，确保歌曲标题准确。
- **阶梯式匹配搜索**：
    - **优先匹配**：保留原始专辑名进行精确搜索，确保版本（如 Live 版、录音室版、周年纪念版）准确。
    - **自动回退**：若原始专辑信息无效，自动切换至“歌手 + 歌名”全局匹配并更新正确的专辑信息。
- **全格式支持**：支持 **MP3, FLAC, M4A (AAC/ALAC), OGG** 格式的元数据写入。
- **高清封面嵌入**：自动从云端获取并嵌入高清（800x800）专辑插图。
- **并行处理**：采用多线程架构，大幅提升数百个文件的批量处理速度。
- **注意注意注意**：歌曲文件格式要按“王力宏 - 在梅边”的格式，可以再音乐软件下载设置里更改。

## 🚀 快速上手

### 1. 软件配置
1. 下载并解压本项目发布的软件包。
2. 运行 `MusicToolPro.exe`。
3. 在左侧边栏点击“浏览”，选择软件包内自带的 `um.exe`（解密引擎）。程序会自动保存此配置。

### 2. 批量解密与自动补全
*此功能适用于处理腾讯音乐、网易云音乐等平台的加密缓存文件（如 .mflac, .mgg, .ncm 等）。*

1. 切换到 **“批量解密”** 标签页。
2. 设置 **输入文件夹**（存放加密文件的路径）和 **输出文件夹**（解密后的存放路径）。
3. 勾选 **“解密后启动‘文件名对齐’补全”**。
4. 点击 **“🔥 开始执行解密任务”**。程序将自动完成：解密 -> 歌名修正 -> 专辑匹配 -> 封面抓取。

### 3. 仅进行元数据补全
*此功能适用于已经是普通音频格式，但缺少封面、专辑名或音轨信息的文件。*

1. 切换到 **“元数据补全”** 标签页。
2. 选择音频所在的文件夹。
3. 点击 **“✨ 执行初步对齐与搜索补全”**。

## 🛠️ 补全逻辑说明

为了确保元数据匹配的高准确率，本项目遵循以下严谨的处理步骤：

1. **初步处理 (Initial Alignment)**：读取文件内部标签。如果歌曲标题与文件名不一致，则以文件名为准，强制修改标签中的 Title（仅修改标题，不破坏其他元数据）。
2. **第一阶段搜索 (Contextual Search)**：使用“对齐后的标题 + 歌手 + 原有的专辑名”进行 API 检索。如果找到标题一致且专辑相似度 > 80% 的结果，则直接锁定该匹配项。
3. **第二阶段搜索 (Global Fallback)**：如果第一阶段无结果，则放弃原有无效专辑名，使用“标题 + 歌手”重新在云端检索，并自动更新文件中的专辑名。
4. **最终写入 (Final Patch)**：根据匹配到的专辑 ID，自动写入正确的音轨序号（Track Number）并嵌入高清专辑封面。
